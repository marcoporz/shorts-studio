# Style

Four visual families. Choose with `style` field in shotlist; affects placeholder colors, pace, transitions, SFX, and grade.

```json
"style": "ps2-crt"
```

Values: `anime90`, `crt`, `ps2`, `frutiger-aero`, `clean`.

---

## Common Rule: Text

- **Bold** font, never thin: contrast is everything on a phone.
- Max **6–8 words** per card.
- Always shadow or outline: text must hold over bright images.
- Margins: 8% each side. On right, leave space for YouTube buttons.
- Don't put text over a face or over game HUD.

## Captions (all styles)

Shorts captions don't follow the decorative style font: they must just be readable.

- Sans **bold** font, white, 55% black panel with shadow. No VT323/Press Start for subtitles.
- Lower third, **max 2 lines**, contained width (default `font_size: 66`, `max_words: 4`).
- **Static**: no bounce, shake, or word-by-word. Video moves, text doesn't.
- Don't cover faces, HUDs, or YouTube/TikTok buttons: if slot is a close-up, consider `position: "middle"`.
- Config lives in shotlist `captions` block; don't edit card manually.

## Automatic Transitions

`glitch`, `flash`, `dip-to-black`, `whip-pan` are alpha overlays generated by script on V3: they survive placeholder replacement. Pick 2–4 turning points, not every cut. `cross-dissolve` is a real transition between clips and stays manual in Edit: free API doesn't create it.

---

## Talking Head (Video with Face)

If you record on video, the face is the most important material: don't cover it.

- **Framing**: face in **upper half**, eyes ~1/3 from top. Leave headroom, cut chest not forehead.
- **Vertical**: record 9:16 if possible. If file is 16:9, `face_fit: "crop"` fills format cropping sides; `"fit"` adds black bars. For centered face, crop is right choice.
- **Captions**: lower third free. If face is very centered, move face up with Transform in Resolve instead of moving captions.
- **Overlay**: logos and text away from eyes and mouth; better corners or lower half, but above caption band.
- **Cuts**: alternate face and b-rol. Full-screen face for 30s tires; 2–4s per block, then show what you're talking about.
- **Grade**: natural skin, don't apply scanline or heavy grain on face. If style is CRT or PS2, keep effect on b-roll and leave face cleaner.
- **Audio**: talking head voice already goes through rough cut and normalization; A1 is that file. Don't raise video clip volume on V1: video is muted, voice is on A1.

## 1. 90s Anime

**References**: cel animation, VHS, robot anime openings, saturated but dirty palette.

| Element | Choice |
|---|---|
| Palette | night blue `#101A3A`, cyan `#25D0FF`, magenta `#FF3E9D`, yellow `#FFD84D`, cream `#F4E9D8` |
| Text BG | night blue 85%, cyan 2px border |
| Font | **Anton**, **Bebas Neue**, **Noto Sans JP** for kanji |
| Motion | fast zooms, lateral pans, 2-frame white flash |
| Transitions | hard cut, whip pan, flash |
| SFX | `whoosh-1`, `impact-1`, `stab-1`, `riser-1` |
| Grade | saturation +10, slightly lifted blacks, slight bloom |
| Grain | yes, 6–10%, visible |
| Avoid | modern gradients, emoji, huge rounded corners |

**Recognition**: looks like a Japanese anime frame recorded on VHS.

---

## 2. CRT

**References**: CRT monitor, scanlines, chromatic aberration, analog noise.

| Element | Choice |
|---|---|
| Palette | black `#050505`, phosphor green `#39FF88`, amber `#FFB000`, warm white `#F2F2E9` |
| Text BG | black 90%, green or amber text |
| Font | **VT323**, **Share Tech Mono**, **Press Start 2P** (titles only) |
| Motion | almost static, micro drift, 1px jitter |
| Transitions | cut, glitch, 3–4 frame distortion |
| SFX | `glitch-1`, `crt-on`, `crt-off`, `typing-1`, `ui-click-1` |
| Grade | high contrast, blown highlights, scanline overlay |
| Grain | noise + scanlines + slight chroma shift |
| Avoid | pastel colors, too-small text |

**Resolve Trick**: Adjustment Clip over entire timeline with *Grain* + *Scanline* (Resolve FX Texture) + light *Chromatic Aberration*. Scanlines can also be generated as PNG and placed on V3 track in Screen mode.

---

## 3. PS2

**References**: 2000–2006 console menus, petrol blue backgrounds, spheres, metallic gradients, low resolution.

| Element | Choice |
|---|---|
| Palette | petrol blue `#0B1E33`, azure `#3FA9F5`, silver `#C9D6E3`, orange `#FF7A1A` |
| Text BG | petrol blue 90%, silver line |
| Font | **Jost**, **Inter Bold**, **Michroma** for titles |
| Motion | slow push-in, 2–3° rotations, scrolling reflections |
| Transitions | short cross dissolve, dip to black |
| SFX | `ps2-boot`, `ui-click-1`, `whoosh-2`, `sub-drop-1` |
| Grade | blue in shadows, cold highlights, slight vignette |
| Grain | low, but soft edges (upscale from 480p) |
| Avoid | 4K sharp, natural colors, thin fonts |

**Trick**: for authentic look, upscale footage to 480p and back to 1080p with light filter (Resolve: *Super Scale* off, *Sharpen* 0). Viewer must "feel" 2004.

---

## 4. Frutiger Aero

**References**: Windows Vista/7, bubbles, glass, waves, green grass + blue sky, fish, optimistic tech.

| Element | Choice |
|---|---|
| Palette | sky `#7FD4FF`, water `#2BB3C0`, green `#8FD14F`, white `#FFFFFF`, deep blue `#123A5A` |
| Text BG | white 90% with deep blue text, or glass blur |
| Font | **Jost**, **Inter**, **Quicksand** |
| Motion | rising bubbles, reflections, slow orbits |
| Transitions | cross dissolve, soft zoom, lens flare |
| SFX | `bubble-1`, `whoosh-2`, `pop-1`, `ui-click-1` |
| Grade | bright, medium saturation, soft highlights, no pure blacks |
| Grain | zero, all clean and glossy |
| Avoid | horror vacui, dirty textures, dark colors |

**Trick**: Frutiger Aero works if **bright**. If gameplay is dark, put it in a glass frame with sky background: contrast is part of the style.

---

## 5. Clean (Fallback)

When video is long and style would become tiring.

- black background, white text, single accent
- font **Inter Bold**
- hard cuts only
- no grain
- minimal SFX (`whoosh-2`, `pop-1`)

## Pairings

| Video Type | Style | Why |
|---|---|---|
| Retro game / PS2 | `ps2` + `crt` | matches material |
| Lore, creepypasta, "forgotten clone" | `crt` or `anime90` | atmosphere |
| Unknown social / indieweb / Y2K | `frutiger-aero` + `crt` | web of that era |
| Game comparison | `ps2` | neutrality + nostalgia |
| Long video, 10+ min | `clean` with themed inserts | readability |

You can change style mid-video: `style` is global, but nothing stops using `anime90` for intro and `clean` for body. Note in `notes.md` and tell the AI.

---

## How Style Reaches Placeholders

Placeholders use `kind` color, not `style`. Style appears:

- in card `style` field (top);
- in suggested animations;
- in marker text;
- in `ANIM` column at bottom.

So you can change style without regenerating everything: just change animation and Fusion templates.

## SFX by Style

| Style | Base Set |
|---|---|
| anime90 | `whoosh-1`, `impact-1`, `stab-1`, `riser-1` |
| crt | `glitch-1`, `crt-on`, `crt-off`, `typing-1` |
| ps2 | `ps2-boot`, `ui-click-1`, `whoosh-2`, `sub-drop-1` |
| frutiger-aero | `bubble-1`, `pop-1`, `whoosh-2`, `ui-click-1` |
| clean | `whoosh-2`, `pop-1` |

Rule: **max 1 SFX every 2–3 seconds**. More than that becomes noise. Sound transition goes on the **cut**, not mid-clip.

## Studio 21.1.1: What Changes for Face & Transitions

- **Face**: with `animation_mode: fusion`, face placeholders are static; any zoom/pan on face goes applied as Fusion comp after replacement (templates in `presets/fusion/`).
- **Native Transitions**: `cross-dissolve` and `dip-to-black` become native Resolve transitions if `native_transitions: true`. `glitch`, `flash`, `whip-pan` remain V3 overlays. Native transitions need handles in placeholders (default 0.6s).
- **Animations**: with `animation_mode: fusion`, animations live in Fusion comp on timeline clip and **survive** placeholder replacement. No need to re-apply.
