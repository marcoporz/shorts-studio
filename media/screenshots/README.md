# media/screenshots/

Screenshot di siti, app, UI, profili social, vecchie versioni di software.

## Come farli bene

- cattura a risoluzione piena, senza barre del browser se non servono
- per i siti: modalità desktop, zoom 100%
- per i profili: oscura i dati personali prima di salvarli
- per i siti vecchi: usa Wayback Machine e cattura la pagina archived
- se ti serve una panoramica, fai più screenshot e montali in un'immagine larga:
  l'animazione `pan-lr` li attraversa

## Nomi

```text
spacehey-home-2005.png
spacehey-profilo-2005.png
myspace-player.png
fallout3-pipboy.png
```

## Uso nello shotlist

`"kind": "screenshot"` → colore viola e animazione consigliata `pan-lr` / `pan-rl`.

Dopo aver aggiunto i file: `scan`.
